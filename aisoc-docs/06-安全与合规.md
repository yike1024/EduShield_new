# 06 安全与合规

> 版本 v0.1 ｜ 2026-08-13
> 读者：全体。本文定义平台的安全边界、审批、审计与伦理要求。

---

## 1. 安全原则

1. **纵深防御**：nginx（入口防护）→ 实例 token（组件互信）→ 授权白名单（目标管控）→ 审批流（写入操作）→ 审计留档（可追溯）
2. **最小权限**：每部件独立 token、独立工具白名单；大脑不重写 agent 循环
3. **AI 不可信**：判定双轨（规则+LLM）、审批兜底、证据可复核
4. **默认拒绝**：不在授权白名单的目标一律拒绝；未审批的写入操作一律拒绝

---

## 2. 鉴权与访问控制

| 层 | 控制 | 说明 |
|---|---|---|
| 外部入口 | nginx TLS + basic auth / IP 白名单（可选） | 生产必上 TLS |
| 大脑 API | 会话认证（token/password）+ 用户隔离 | 多用户各自任务隔离 |
| 部件实例 | `--auth token`（Bearer） | 大脑注册表持有 token，防实例被直调 |
| 内部组件 | 部件不直连（星型）；token 只在大脑↔部件间传递 | 见 01 |

**token 管理**：大脑生成、注册表登记、可轮换；token 不落日志（reasonix 日志中间件不记 query，token 经 header 传递）。

---

## 3. 授权白名单（目标管控）

- 大脑保存授权名单：允许扫描/处置的目标（IP/域名/网段 + 有效期 + 授权人）
- **两道校验**：
  1. 大脑创建任务时校验 target ∈ 白名单（第一道）
  2. 部件工具内部复核（第二道，防绕过大脑直调实例）
- 不在名单 → 任务拒绝执行并记 ledger
- 名单变更需审批并留痕

```json
{
  "targets": [
    {"target": "10.0.0.0/24", "scope": "scan", "expires": "2026-12-31", "owner": "张老师"},
    {"target": "8.215.92.252", "scope": "scan,block", "expires": "2026-09-30", "owner": "李老师"}
  ]
}
```

---

## 4. 审批流（写入操作）

**必须人工审批的操作**（工具分类为写入/高风险）：

- 防火墙封禁 / 解封（firewall_block/unblock）
- 漏洞利用、配置修改、目标外操作
- 沙箱逃逸、memory 写入、受管配置修改（reasonix 强制 fresh-human-approval，连自动模式都不能代批）

**流程**：任务进入 `approval` 状态 → 前端面板/通知审批人 → 确认/拒绝 → 结果写入 ledger → 超时（默认 5 分钟）视为拒绝。

---

## 5. 审计留档（合规要求）

| 要求 | 实现 |
|---|---|
| 思维链全流程留痕 | ledger 表：谁/何时/做了什么/为什么（prompt→工具→证据→理由） |
| 留档 ≥ 180 天 | SQLite 保留 + 每日备份；归档而非删除 |
| 可导出 | 任务/发现/判定/审批/报告一键导出（JSON/Markdown） |
| 日志不含敏感信息 | 日志不记 query/header/token；reasonix 侧 4 层错误脱敏 |
| 处置复核 | 封禁等处置后自动生成复核任务（可选二期） |

---

## 6. 数据保护

- API Key / token：只存 `.env`（权限 600）或大脑密钥库，不进配置/代码/日志
- 证据数据（Finding/报告）属敏感数据：数据库权限 700，访问走大脑 API（有鉴权）
- 靶场/真实目标扫描数据：最小化留存，按授权有效期自动过期提醒

---

## 7. 伦理与合规边界（全员义务）

1. **只测授权目标**：白名单外一律禁止；靶场失效（如 edushield_key 已失效）不擅自扩大目标
2. **负责任披露**：发现的真实漏洞走报告流程，不在平台外泄露
3. **最小影响**：不做 DoS、不做未授权暴力破解；扫描频率受控（限流）
4. **合规**：遵守《网络安全法》、等保 2.0、数据隐私法规
5. **AI 局限**：LLM 判定可能幻觉，高危判定必须人工复核（双轨+审批兜底）

---

## 8. 已知风险与对策（持续更新）

| 风险 | 等级 | 对策 |
|---|---|---|
| 沙箱 off（bash="off"）致工具无隔离 | 中 | 实例 token 保护 + 白名单双重校验；仅必要部件开 off |
| LLM 判定幻觉 | 高 | 双轨判定 + 校准基线（误报≤20%、漏报=0）+ 人工复核 |
| 事件流串扰（单实例多任务） | 高 | 端口级隔离（一部件一实例）已解决 |
| 靶场 key 失效 | 中 | 轮换密钥/换靶场（已记录在计划书风险表） |
| 平台范围膨胀 | 高 | 一期只做 A+B 两部件，情报/应急二期明确延后 |
| 成本失控 | 中 | 每任务 token 预算（params.max_steps）+ 余额监控告警 |
