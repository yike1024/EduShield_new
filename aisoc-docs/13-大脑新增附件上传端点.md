# 大脑（6657）新增"附件上传"HTTP 接口

**需求方**：caoyike（前端） / **实施方**：linyuxuan（大脑）
**目标**：让 web 版本（HTTP API 模式）也能上传文件给大脑做日志审计
**状态**：待 linyuxuan 实施

---

## 1. 背景与现状

### 1.1 用户场景

caoyike 在 web 模式（`serve_frontend.py` 跑在 3000 端口代理到大脑 6657）下，想把一个 log 文件拖进聊天 Composer，让大脑驱动日志审计部件分析。

### 1.2 现状（修这个之前）

- 主聊天 Composer 的 `<input type="file">` 存在，UI 看着像能传；
- 拖文件后调用 `app.SavePastedFile(name, dataUrl)`，但 web 模式下走 `bridge.ts:534-589 createHttpApiBinding()` 的 HTTP API 分支；
- 切换 switch 里**没有 `SavePastedFile` 这条 case**，落到 `default` 分支 `return undefined`（`bridge.ts:578-580`）；
- 附件 `path` 是 undefined，brain 永远查不到 `web-attachment://file-...`，附件内容丢光；
- 用户看到日志审计 agent 不工作（其实是大脑根本没收到文件内容）。

### 1.3 Wails 桌面端 vs Web 端

| 模式 | 入口 | SavePastedFile 真能写盘？ |
|---|---|---|
| Wails 桌面 | `desktop/app.go:9120 → control.SaveAttachmentDataURL` → 落盘 `.reasonix/attachments/` | ✅ 是 |
| Web（HTTP API） | **当前无实现，返回 undefined** | ❌ 否 |
| Mock（开发） | `bridge.ts:3390-3394` 把 dataUrl 塞 Map，重启即丢 | ⚠️ UI 假象 |

**修这个需求 = 给大脑加一个 HTTP 端点，桥接到已有的 `control.SaveAttachmentDataURL`。**

## 2. 改动范围（最小补丁）

### 2.1 新增 HTTP 端点（大脑侧 / 必做）

**文件**：`internal/serve/serve.go`

#### 2.1.1 注册路由（在 `handler()` mux 里添加）

```go
mux.HandleFunc("POST /save-attachment", s.saveAttachment)
```

> 路径建议 `/save-attachment`（保持和现有 `/submit`/`/approve` 同级，不带 `/api` 前缀；前端会通过 `serve_frontend.py` 的路由表带前缀转发）。

#### 2.1.2 实现 handler（紧接现有 handler 风格）

参考 `serve.go:517` 的 `s.submit` 写法：

```go
// saveAttachment stores a non-image file attachment (base64 dataURL) under
// .reasonix/attachments/ and returns its repo-relative path. Mirrors the
// desktop (Wails) SavePastedFile flow but exposed over HTTP so the web
// frontend can upload files for brain-mediated analysis (log audit, etc.).
//
// POST /save-attachment
// Content-Type: application/json
// Body: {"name": "access.log", "dataUrl": "data:text/plain;base64,..."}
// 200: {"path": ".reasonix/attachments/clipboard-20260904-153022.123456-1.log"}
// 4xx: {"error": "<reason>"}                // invalid body
// 413: attachment must be between 1 byte and 25 MB
func (s *Server) saveAttachment(w http.ResponseWriter, r *http.Request) {
    type req struct {
        Name    string `json:"name"`
        DataURL string `json:"dataUrl"`
    }
    var body req
    if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
        writeError(w, http.StatusBadRequest, fmt.Sprintf("decode body: %v", err))
        return
    }
    if body.Name == "" || body.DataURL == "" {
        writeError(w, http.StatusBadRequest, "name and dataUrl are required")
        return
    }
    // Delegate to the existing, well-tested desktop-side implementation.
    // It enforces the 25 MB cap and writes under REASONIX_HOME/.reasonix/attachments/.
    rel, err := control.SaveAttachmentDataURL(body.Name, body.DataURL)
    if err != nil {
        // Distinguish size errors (413) from decode errors (400).
        if strings.Contains(err.Error(), "between 1 byte and 25 MB") {
            writeError(w, http.StatusRequestEntityTooLarge, err.Error())
            return
        }
        writeError(w, http.StatusBadRequest, err.Error())
        return
    }
    writeJSON(w, http.StatusOK, map[string]string{"path": rel})
}
```

> `writeJSON` / `writeError` —— 看 `serve.go` 里现有 handler 用的什么辅助函数，照风格写。最简的备选：`json.NewEncoder(w).Encode(...)` + `http.Error(w, msg, code)`。

`control.SaveAttachmentDataURL` 已在 `internal/control/attachments.go:33` 实现，**零修改**。

### 2.2 serve_frontend.py 路由表（前端侧 / caoyike 改）

**文件**：`serve_frontend.py:26-32`

新增路由是 `/save-attachment`，因为属于 `/api/*` 通配，已被现有 `("/api", "http://127.0.0.1:6657", False)` 自动覆盖，**无需改 proxy**。

**建议路径**：`POST /save-attachment`（与现有 `/submit`、`/approve`、`/cancel` 同级，最干净）。

### 2.3 前端 HTTP API 桥接（caoyike 改）

**文件**：`desktop/frontend/src/lib/bridge.ts:534-589`

在 `createHttpApiBinding()` 的 Proxy `switch (methodName)` 里加一条：

```typescript
case 'SavePastedFile':
  // web 版本下让浏览器前端走大脑 HTTP 上传端点（替代 Wails 桥）。
  // 数据流：base64 dataURL → POST 大脑 → 落盘 .reasonix/attachments/ → 返回相对路径
  return await httpClient.savePastedFile(args[0] as string, args[1] as string);
```

并在 `httpClient` 对象补一个 `savePastedFile(name, dataUrl)` 方法：

```typescript
async savePastedFile(name: string, dataUrl: string): Promise<string> {
  const resp = await fetch(`${this.baseUrl}/save-attachment`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name, dataUrl }),
    credentials: 'include',          // 跟现有 httpClient 一致，带 cookie 走 auth.middleware
  });
  if (!resp.ok) {
    const txt = await resp.text();
    throw new Error(`save-attachment ${resp.status}: ${txt}`);
  }
  const j = await resp.json() as { path: string };
  return j.path;
}
```

> `baseUrl` 看你前端里 `httpClient` 当前指向哪个地址（应该是 `/api` → 3000 → 6657）。具体看 `bridge.ts:496` 附近的 `getHttpClient()`。

### 2.4 auth 检查（重要 / 不要忘）

现有 brain 路由都走 `s.auth.middleware(csrfGuard(mux))`（`serve.go:347`）：

- ✅ auth 自动覆盖新路由，**无需手动加**；
- ✅ csrfGuard 自动要求 `Content-Type: application/json`，前端已发 JSON，**无需改动**；
- ⚠️ 如果当前 web 用户**未登录**，auth middleware 会 401。前端 `httpClient` 的 `credentials: 'include'` 必须带上 cookie（已写）。

## 3. 端到端验证步骤

### 3.1 单接口验证（curl）

```bash
# 1. 健康检查（确认 6657 在跑）
curl -s http://127.0.0.1:6657/status

# 2. 上传一个小文件
echo "hello attachment" | base64
# → "aGVsbG8gYXR0YWNobWVudA=="
curl -s -X POST http://127.0.0.1:6657/save-attachment \
  -H 'Content-Type: application/json' \
  -d '{"name":"hello.txt","dataUrl":"data:text/plain;base64,aGVsbG8gYXR0YWNobWVudA=="}'

# 期望响应：
# {"path":".reasonix/attachments/clipboard-20260904-153022.123456-1.txt"}

# 3. 验证文件真落了
ls -la ~/.reasonix/attachments/

# 4. 大小超限（应 413）
python3 -c "
import base64, json
b = b'a' * (30 * 1024 * 1024)
print(json.dumps({'name':'big.bin','dataUrl':'data:application/octet-stream;base64,' + base64.b64encode(b).decode()}))
" > /tmp/big.json
curl -s -o /dev/null -w '%{http_code}\n' -X POST http://127.0.0.1:6657/save-attachment \
  -H 'Content-Type: application/json' -d @/tmp/big.json
# 期望: 413
```

## 5. 风险与回滚

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| `auth.middleware` 拒掉未登录 web 用户 | 中 | 前端拿 401 | 确保前端 `credentials: 'include'`；cookie session 由现有登录流程发 |
| 大文件 30 MB base64 把请求体撑爆 | 低 | 内存峰值 | 当前 25 MB 上限已卡；proxy `timeout=3600` 已给足时间 |
| 写盘失败导致 rel path 错 | 极低 | 单次 5xx | `SaveAttachmentDataURL` 已有原子写（创建 + 失败回滚 unlink，`attachments.go:113-125`） |

**回滚**：删一行 `mux.HandleFunc("POST /save-attachment", s.saveAttachment)` + 删 handler 函数即可。
