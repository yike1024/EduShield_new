## 2. 系统定位

校园智盾 AiSOC 是一个**多 Agent 安全运营平台**，由三部分构成：

```
┌─ 大脑（一个）    FastAPI 平台层（6657）：编排 · 判定 · 知识库 · 会话 · 审计 · 报告
├─ 身体部件（多个）  reasonix serve 实例（8787 渗透 / 8788 审计 / …）：领域执行
└─ 接入层          nginx 单入口（80/443）：外部唯一暴露点，子域名路由
```

设计三条铁律（详见各文档）：

1. **一部件一实例一端口**（端口级隔离，禁止命令级混跑）
2. **星型拓扑**：部件间禁止直连，证据与判定必须过大脑
3. **AI 只加在判断/生成处**，流程/状态/存储用纯业务代码

## 3. 术语表

| 术语 | 含义 |
|---|---|
| **大脑（Brain）** | FastAPI 平台层（端口 6657），平台的唯一中枢，负责编排、判定、存储、审计、报告 |
| **身体部件（Body/Part）** | 一个领域执行单元 = 独立 reasonix serve 实例 + 领域工具集 + 领域 SKILL.md + 领域报告模板 |
| **部件注册表** | 大脑侧维护的 `domain → {host, port, token}` 映射，任务按 domain 路由 |
| **统一协议** | 大脑与部件之间通信的三张数据表：TaskMessage / Finding / Report |
| **TaskMessage** | 任务下发协议：`{task_id, domain, target, params, tools}` |
| **Finding** | 证据协议：`{id, target, tool, severity, cve, cwe, cvss, remediation, confidence, timestamp}` |
| **Report** | 报告协议：`{task_id, domain, summary, findings[], verdict, confidence, mitre[], appendix}` |
| **verdict / confidence** | 威胁判定结论（真实攻击/误报/待核实）及其置信度 |
| **思维链账本（Ledger）** | 每一步（prompt → 工具调用 → 证据 → 判断理由）的结构化审计记录 |
| **授权白名单** | 允许扫描/处置的目标清单（IP/域名/网段），不在名单内一律拒绝 |
| **审批流** | 写入类操作（封禁、利用、配置修改）需人工确认的流程 |
| **SSE** | Server-Sent Events，reasonix serve 的事件流通道（`/events`），大脑经此流式接收部件输出 |
| **EventHub** | 大脑模块：常驻订阅各部件 SSE，补上 `task_id`/`domain` 标注后经 `/api/stream` 推给前端，是全平台实时面板的数据枢纽 |
| **实时面板** | 前端功能：Agent 状态墙（哪个 agent 做哪个事）+ 流式输出区（SSE 实时追加），替代一次性结果展示 |
| **behind-proxy** | reasonix serve 启动标志，开启后才信任 `X-Forwarded-For/Proto`（反代场景必开） |
| **部件公式** | 身体部件的最小构成：内核（reasonix-core）+ 领域工具 + 领域技能 + 领域报告模板 |
| **误报抑制** | 内置"搜索引擎爬虫≠攻击、选课/查分高并发≠DDoS"等校园场景规则，降低误报率 |
| **AiSOC** | AI Security Operations Center，AI 驱动的安全运营中心 |

## 4. 关键决策记录（2026-08 评审确认）

| 决策 | 结论 | 依据 |
|---|---|---|
| 通信总线 | HTTP REST 主 + MCP 插件辅 | 计划书 3.5 |
| 多部件隔离 | 端口级（一部件一实例一端口） | 本文档集 01 |
| 外部暴露 | nginx 单入口（80/443），实例收回归环 | 本文档集 01/05 |
| 部件协作 | 星型拓扑，禁止直连，证据过大脑 | 本文档集 01 |
| 大脑实现 | Python FastAPI（EduShield 扩展） | 计划书 3.5 |
| 内核实现 | Go reasonix-core（每部件一实例） | 计划书 3.5 |
| 知识库 | 复用 EduShield ChromaDB（33 条资产起步） | 计划书 7 |
| 证据存储 | SQLite，审计留档 ≥ 180 天 | 计划书 7 |
