# 05 部署与运维手册

> 版本 v0.1 ｜ 2026-08-13
> 读者：运维（成员 A 兼）。本文以现有部署（本机 127.0.0.1）为基线。

## 1. 部署总览

```
外部用户 ──▶ nginx(80/443) ──▶ brain.campus → 127.0.0.1:6657（大脑）
                            ├── pentest.campus → 127.0.0.1:8787（渗透）
                            └── audit.campus → 127.0.0.1:8788（审计）
```

**安全基线**：nginx 是唯一对外暴露点；大脑与所有部件只监听 `127.0.0.1`；每个实例带 `--auth token`。

## 2. 部件实例启动（reasonix serve）

```bash
cd /home/wangwei/DeepSeek-Reasonix

# 渗透部件（示例）
REASONIX_HOME=/home/wangwei/.serve-home \
nohup ./bin/reasonix serve \
  --addr 127.0.0.1:8787 \
  --auth token \
  --behind-proxy \
  >> serve-8787.log 2>&1 &

# 日志审计部件（新实例，端口 8788，独立 REASONIX_HOME 与 token）
REASONIX_HOME=/home/wangwei/.serve-audit \
nohup ./bin/reasonix serve \
  --addr 127.0.0.1:8788 \
  --auth token \
  --behind-proxy \
  >> serve-8788.log 2>&1 &
```

| 参数 | 说明 |
|---|---|
| `--addr 127.0.0.1:<port>` | 只监听回环，外部不可直达 |
| `--auth token` | 开启 token 认证（token 未指定时自动生成并打印；生产环境用 `--token` 预置并登记到部件注册表） |
| `--behind-proxy` | 信任 nginx 注入的 `X-Forwarded-For/Proto`（不开启则反代后客户端 IP 全部是 127.0.0.1） |
| `REASONIX_HOME` | 每部件独立状态目录（会话/配置/凭据互不共享） |

**启动自检**：
```bash
curl -s http://127.0.0.1:8787/status        # 应返回状态 JSON
curl -s http://127.0.0.1:8787/ -H "Authorization: Bearer <token>"   # 带 token 可访问
```

## 3. nginx 反向代理配置

### 3.1 核心 server 块（SSE 兼容是重点）

```nginx
map $http_upgrade $connection_upgrade {
    default upgrade;
    ''      close;
}

server {
    listen 80;
    server_name brain.campus;

    location / {
        proxy_pass http://127.0.0.1:6657;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 80;
    server_name pentest.campus;

    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        # ↓ SSE 三件套：必须关缓冲，否则事件流被 nginx 攒住不推给大脑
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }
}
```

### 3.2 必知要点

| 要点 | 原因 |
|---|---|
| `proxy_buffering off` | SSE 流式转发必需；否则事件帧被缓冲，大脑收不到实时输出 |
| `proxy_read_timeout 3600s` | 长任务（渗透扫描可达数十分钟）防止 nginx 掐断空闲连接 |
| 子域名路由而非路径前缀 | serve 页面资源是根路径绝对地址（`/assets/...`），`/pentest/` 前缀会 404 |
| `X-Forwarded-For` 注入 | 配合 `--behind-proxy` 让 serve 看到真实客户端 IP（限速/审计用） |
| **TLS** | 生产环境 443 + 证书；内网演练可先 HTTP |

```

```

## 4. 部件注册表运维

大脑 `registry/` 配置（JSON/TOML）：

```json
{
  "brain":     {"host": "127.0.0.1", "port": 6657},
  "pentest":   {"host": "127.0.0.1", "port": 8787, "token": "<tk_pentest>", "auth": "token"},
  "logaudit":  {"host": "127.0.0.1", "port": 8788, "token": "<tk_logaudit>", "auth": "token"}
}
```

- 新增部件流程：分配端口（见 01 端口表）→ 启动实例 → 生成 token → 注册表登记 → 大脑热加载
- token 轮换：改 serve `--token` → 同步注册表 → 验证健康

## 5. 密钥与凭据管理

| 资产 | 位置 | 要求 |
|---|---|---|
| DeepSeek API Key | `~/.reasonix/.env`（及每部件 REASONIX_HOME/.env） | 权限 600，不进配置文件/代码/日志 |
| 部件 token | 注册表（大脑侧）+ serve `--token` | 大脑生成、按部件隔离，可轮换 |
| SSH 密钥 | 按需（如 edushield_key） | 权限 600；**已知 edushield_key 对 8.215.92.252 已失效，需轮换** |
| 数据库 | SQLite（大脑） | 目录权限 700，含审计留档不可随意删 |

## 6. 监控与健康检查

| 对象 | 检查 | 频率 |
|---|---|---|
| 大脑 | `GET /api/health` | 30s |
| 各部件 | `GET /status`（运行/余额/用量） | 30s |
| SSE 订阅 | 大脑侧连接数/断连告警 | 实时 |
| 任务 | 状态机异常（长时间 pending/running）告警 | 1min |
| 余额 | 部件 `/status` balance（当前 deepseek 余额 ≈ ¥3.26，注意成本） | 1h |

**日志**：大脑访问日志 + serve.log 保留 ≥180 天（审计要求）；日志中不得出现 token/API key（reasonix 日志中间件默认不记 query）。

---

## 7. 备份与恢复

- SQLite（tasks/findings/ledger/reports）每日备份，保留 ≥180 天
- 部件会话目录（REASONIX_HOME/projects/...）随实例重建，可丢（证据已上报大脑）
- 恢复演练：季度一次，从备份恢复 SQLite + 重启 nginx/实例

## 8. 常用运维命令速查

```bash
# 查看部件是否活着
ss -tln | grep -E '6657|8787|8788'

# 查看 serve 日志尾部
tail -20 /home/wangwei/DeepSeek-Reasonix/serve-8787.log

# 重启部件（同启动命令，先 kill 旧进程）
kill <pid> && <启动命令>

# 校验 nginx 配置
nginx -t && systemctl reload nginx

# 测试反代连通（经 nginx）
curl -s http://pentest.campus/status
```
